# DEDAL DES COULEURS

Site vitrine de la galerie d'art DEDAL DES COULEURS (Paris), intégré à partir de la maquette Figma.

## Pages
- `index.html` — Accueil
- `galerie.html` — La Galerie
- `oeuvres.html` — Les Œuvres (avec filtres)
- `inscription.html` — Inscription à la newsletter

## Technique
- HTML5 / CSS3, sans framework
- Responsive en **mobile first** : styles de base pour smartphone, puis media queries à 768px (tablette) et 1024px (ordinateur)
- Polices Cormorant Garamond et Inter hébergées dans `fonts/` (licence SIL Open Font License)
- Petit JavaScript (`js/script.js`) : menu burger, filtres des œuvres, message du formulaire
- Pages validées sans erreur au validateur W3C (HTML et CSS)
